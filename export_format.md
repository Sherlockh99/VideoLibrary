# Формат экспорта VideoLibrary

Универсальный формат для обмена данными между десктопным (Python) и мобильным (Android) приложениями.

## Спецификация (версия 1)

**Расширение файла:** `.vlp` (Video Library Package) — JSON-файл  
**Кодировка:** UTF-8

### Структура корневого объекта

```json
{
  "format": "videolibrary",
  "version": 1,
  "exported_at": "2025-02-15T12:00:00Z",
  "source": "desktop",
  "movies": []
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `format` | string | Всегда `"videolibrary"` — идентификатор формата |
| `version` | int | Версия формата (для обратной совместимости) |
| `exported_at` | string | ISO 8601 дата/время экспорта |
| `source` | string | `"desktop"` или `"android"` |
| `movies` | array | Массив объектов фильмов |

### Объект фильма

```json
{
  "tmdb_id": 603,
  "title": "Матрица",
  "original_title": "The Matrix",
  "genres": "Фантастика, Боевик",
  "rating": 8.7,
  "overview": "Описание фильма...",
  "release_date": "1999-03-31",
  "poster_path": "/f89U3ADr1oiB1s9GkdPOEpXUk5H.jpg",
  "personal_rating": 5
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `tmdb_id` | int | да | ID в TMDb (фильма или сериала) |
| `media_type` | string | нет | `"movie"` или `"tv"`. По умолчанию `"movie"` (для старых файлов) |
| `title` | string | да | Название (локализованное) |
| `original_title` | string | нет | Оригинальное название |
| `genres` | string | нет | Жанры через запятую |
| `rating` | float | нет | Рейтинг TMDb (0–10) |
| `overview` | string | нет | Описание |
| `release_date` | string | нет | Дата выхода (YYYY-MM-DD) |
| `poster_path` | string | нет | Путь к постеру TMDb (без домена) |
| `personal_rating` | int | нет | Личная оценка (1–5) |

**Примечание:** Изображения не включаются в файл. Постер загружается по `https://image.tmdb.org/t/p/w500` + `poster_path`.

### Правила импорта

- При импорте фильм с `tmdb_id`, уже существующий в базе, считается дубликатом
- Поведение при дубликате: **пропустить** или **обновить** (обновить `personal_rating` и др.)
- Рекомендация: по умолчанию **пропускать** дубликаты, опция "заменить существующие" при импорте
