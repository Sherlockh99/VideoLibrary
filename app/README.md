# VideoLibrary — мобильное приложение

Android-приложение для управления видеоколлекцией. Совместимо с десктопной версией (movie_manager) через общий формат .vlp.

## Запуск

1. Получите API-ключ TMDb: https://www.themoviedb.org/settings/api

2. Введите ключ в настройках приложения (Settings → TMDb API key).

3. Соберите и установите:
   ```
   ./gradlew assembleDebug
   ```

## Функции

- Поиск фильмов на TMDb
- Коллекция с постерами (Coil — кеш в памяти и на диске)
- Личная оценка 1–5
- **Экспорт/импорт** в формате .vlp — тот же файл работает с Python-программой

## Формат .vlp

Файлы .vlp универсальны: экспорт из Android можно импортировать на десктопе и наоборот.
Спецификация: [export_format.md](../export_format.md)
